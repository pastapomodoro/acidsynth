# AcidSynth

UI minimal e responsive ispirata a Teenage Engineering

- Ogni slider/controllo è in un box separato, con label, slider e valore numerico ben distanziati
- Nessun overlapping, layout ordinato e arioso
- Look moderno, colori neutri, accenti arancio/azzurro
- Responsive: perfetto su desktop e mobile

## Come avviare

1. Installa le dipendenze:
   ```sh
   npm install
   ```
2. Avvia la build:
   ```sh
   npm run build
   ```
3. Apri `test/index.html` in un browser moderno
